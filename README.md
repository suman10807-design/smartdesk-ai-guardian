# smartdesk-ai-guardian
SMARTDESK AI — Intelligent Study Guardian
## About the Project

SMARTDESK AI GUARDIAN is an intelligent study companion designed to help students maintain focus, manage study sessions, and build better study habits.

## Main Features

- Custom study timer
- Voice-controlled AI assistant
- Robotic-style voice responses
- Webcam-based presence monitoring
- Distraction alerts
- Automatic pause when you leave your desk
- Automatic resume when you return
- Manual study breaks
- Study activity tracking
- Daily focus report

## Project Files

- `index.html` — Main application
- `styles.css` — Application design
- `storage.js` — Stores study statistics
- `voice.js` — Voice assistant
- `scheduler.js` — Break management
- `guardian.js` — Presence monitoring
- `app.js` — Main application logic

## How to Use

1. Open SMARTDESK AI GUARDIAN in your browser.
2. Set your desired study duration.
3. Start your study session.
4. Enable camera permission if you want webcam monitoring.
5. Use voice commands or the dashboard to manage your session.
6. Take breaks whenever needed.

## Privacy

Camera access requires your permission. Camera footage is not uploaded by this application.

## Project Vision

To create a smart digital study environment that encourages concentration, discipline, and productive learning.
